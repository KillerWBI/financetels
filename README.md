# Смены и деньги

Учёт дохода по сменному графику: календарь смен, зарплата на руки, премия через месяц,
обязательные платежи «от и до», цели и потенциальные доходы.

## Как считается

- Дневная смена 6:00-16:30, ночная 17:30-4:00, оплачивается 10 часов.
- Ставка 33,40 zł/ч днём и 38,40 zł/ч в ночные часы (21:00-4:00). Неоплачиваемые 0,5 ч вычитаются из дневной части.
- Выходной (суббота, воскресенье, по дню начала смены): x1,5. Доп. смена: x2 в будни, x2,5 в выходной.
- Любой день можно настроить вручную: тип смены (дневная, ночная, нет), доп. смена, и «выходной» в трёх положениях: по календарю, выходной (праздник, перенос) или будний. Комбинации складываются: ночная + доп. + выходной = x2,5.
- На руки = brutto x 0,77. Доходы, которые вы вписываете сами, идут без налога.
- Премия 15% от brutto за месяц, потом x0,77. 7-го числа приходит зарплата за прошлый месяц и премия за позапрошлый.
- Все ставки и множители меняются на странице «Настройки».

Расчёт лежит в `shared/core.ts` (чистые функции), тесты в `server/test`.

## Быстрый запуск без PostgreSQL (данные в памяти)

    npm install
    npm run dev:memory -w server     # API на :3001
    npm run dev -w client            # интерфейс на :5173

## Запуск с PostgreSQL

    createdb budget
    export DATABASE_URL=postgres://user:pass@localhost:5432/budget
    export JWT_SECRET=любая-длинная-случайная-строка
    npm run start -w server          # таблицы создаются автоматически
    npm run dev -w client

Для production: `npm run build -w client`, папку `client/dist` отдаёт любой веб-сервер с прокси `/api` на :3001.

## Проверки

    npm test                          # расчёты, API (server) и сквозные тесты календаря (client)
    npm run typecheck -w server
    npm run typecheck -w client
