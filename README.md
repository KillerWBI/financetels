# Смены и деньги

Учёт дохода по сменному графику: календарь смен, зарплата на руки, премия через месяц,
обязательные платежи «от и до», цели и потенциальные доходы.

## Как считается

- Дневная смена 6:00-16:30, ночная 17:30-4:00, оплачивается 10 часов.
- Ставка 33,40 zł/ч днём и 38,40 zł/ч в ночные часы (21:00-4:00). Неоплачиваемые 0,5 ч вычитаются из дневной части.
- Выходной (суббота, воскресенье, по дню начала смены): зарплата обычная, надбавка +50% уходит в премию (и входит в базу 15%: премия = 15% × (зарплата + надбавка) + надбавка) (приходит месяцем позже, с налогом x0,77); у доп. смен надбавка остаётся x2 / x2,5 в зарплате. Доп. смена: x2 в будни, x2,5 в выходной.
- Любой день можно настроить вручную: тип смены (дневная, ночная, нет), доп. смена, и «выходной» в трёх положениях: по календарю, выходной (праздник, перенос) или будний. Комбинации складываются: ночная + доп. + выходной = x2,5.
- На руки = brutto x 0,77. Доходы, которые вы вписываете сами, идут без налога.
- Премия 15% от brutto за месяц, потом x0,77. 7-го числа приходит зарплата за прошлый месяц и премия за позапрошлый.
- Все ставки и множители меняются на странице «Настройки».

Расчёт лежит в `shared/core.ts` (чистые функции), тесты в `server/test`.

## Быстрый запуск без PostgreSQL (данные в памяти)

    npm install
    npm run dev:memory -w server     # API на :3001
    npm run dev -w client            # интерфейс на :5173

## Запуск с PostgreSQL

    createdb budget
    export DATABASE_URL=postgres://user:pass@localhost:5432/budget
    export JWT_SECRET=любая-длинная-случайная-строка
    npm run start -w server          # таблицы создаются автоматически
    npm run dev -w client

Для production: `npm run build -w client`, папку `client/dist` отдаёт любой веб-сервер с прокси `/api` на :3001.

## Проверки

    npm test                          # расчёты, API (server) и сквозные тесты календаря (client)
    npm run typecheck -w server
    npm run typecheck -w client

## Установка на телефон

Сайт работает как приложение (PWA): манифест, иконки, service worker. iPhone: Safari → «Поделиться» → «На экран Домой». Android: Chrome → меню → «Установить приложение».

## Восстановление доступа (бета, без почты)

На странице входа «Забыли пароль?». Работает, только если на сервере задана переменная `RECOVERY_KEY` (не короче 16 символов): по ключу показывается список аккаунтов (email, число смен/платежей) и выдаётся ссылка сброса на 30 минут, одноразовая. 10 неверных ключей подряд блокируют попытки на 15 минут. Для постоянной работы лучше удалить переменную после восстановления или заменить на почтовый сброс.

## Баланс: сколько есть, сколько будет, можно ли тратить

Вкладка «Баланс». Точка отсчёта — ваша ручная проверка «реально на счету X на дату D» (последняя по дате). От неё считаются: выплаты (7-го: зарплата за прошлый месяц + премия за позапрошлый), платежи по их дням, подтверждённые доходы; повседневные траты (`monthlyLiving`) вычитаются равномерно по дням. Потенциальные доходы показываются отдельным сценарием «с ожидаемыми» и в «можно потратить» не входят.

«Можно потратить» = расчётный остаток сейчас − платежи до ближайшей выплаты − повседневные траты до выплаты + подтверждённые доходы до выплаты. Минус резерв на цели в месяц даёт «свободно после целей». Каждая новая проверка запоминает, что показывал расчёт, и считает разницу.
